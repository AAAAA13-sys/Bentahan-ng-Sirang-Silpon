# Rule: Karpathy Behavioral Heuristics

1. **Think Before Coding**: State assumptions explicitly. Never make silent guesses on ambiguous requirements.
2. **Simplicity First**: Write the simplest code that solves the problem. Avoid premature abstractions and speculative features.
3. **Surgical Precision**: Minimal diffs only. Touch only the files and lines necessary. Never reformat or touch unrelated code.
4. **Goal-Driven Execution**: Formulate hypotheses, define explicit verification criteria, and test empirically before marking tasks complete.
